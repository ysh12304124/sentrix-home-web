# Agent 2.1 W4 — Paraphrase Robustness Report

日期：2026-08-20 ｜ 测试集：`paraphrase-robustness`（88 题 = 22 道单轮可答题 × 4 种改写）｜ Judge：`doubao-seed-2.0-lite`
> 定位：**Paraphrase Robustness Set**（非 Holdout）。GT（参考答案/检索图/预期动作）沿用父题，答案不变，只改表述。

## 1. 测试设计

- 22 道单轮可答题（GT=answer），每题 4 个手写改写，覆盖 4 种风格：
  - **syntax**：换句式结构
  - **lexicon**：换同义词/口语化
  - **order**：换语序/加修饰
  - **angle**：换提问角度（"在哪"→"是什么地方"）
- 手写避免 LLM 注入错误事实；多轮引用题（b2-01/02/03）不纳入（referen 测试另议）。
- run：`20260820-164815`（12B `527f8f` / Qwen 0.8B `d8a8b4`），与 Agent 2.0 干净配置一致。

## 3. 按改写风格拆解

| 风格 | 12B AQ | Qwen 0.8B AQ | 说明 |
| --- | --- | --- | --- |
| syntax（句式） | **1.048** | **0.409** | 最稳：只改句式，planning/检索几乎不受影响 |
| lexicon（同义词） | 0.762 | 0.429 | 中等 |
| order（语序/修饰） | 0.714 | 0.364 | 中等 |
| angle（角度） | **0.591** | **0.238** | 最脆：改提问角度最容易让 Planner/检索跑偏 |

**两个模型一致：syntax > lexicon ≈ order > angle。** 说明 Agent 2.0 对"换个说法"中等敏感，尤其怕换提问角度。

## 4. 逐题稳定性（节选）

- **稳定/改善**：q01（12B：原 1 → 改写 2/2/1/2）、q02（12B：全 2）、q26-q07（12B 全 2）——表述变化不影响。
- **退化明显**：q26-q06（12B：原 2 → [2,0,2,0]）、q47-q04（12B：原 2 → [2,0,0,1]）、q40-q01（12B：原 1 → [0,1,0,0]）、q47-q07（Qwen：原 2 → [1,0,2,0]）。
- **本来就难的不变**：q03/q08/q24-01/q26-01/q26-03/q47-03（原 0 → 改写也 0）——这些是检索/视觉/OCR 硬伤，与措辞无关。

## 5. 结论

1. **Agent 2.0 对自然语言表述中等敏感**：同题换个说法，可答题 AQ 掉 ~20%（12B -19%、Qwen -21%）。
2. **敏感性集中在 Planner/Retrieval**：换"提问角度"最伤（angle 掉最多），说明 Planner 对问题语义的理解和 search_memories 的 query 构建依赖措辞——**这和 W2.1 的 R1 检索瓶颈是同一根因**（检索对自然语言召回不足）。
3. **写作/证据层稳定**：syntax 改写几乎不掉分，说明 Agent 2.0 的"证据→答案"写作链路对表述不敏感；掉分在上游（规划/检索）。
4. **这不是 Holdout 结论**：本 set 是 paraphrase robustness 度量，用于暴露"措辞敏感点"，为 Planner/Retrieval 的鲁棒性优化提供靶点，不代表泛化失败/成功。

## 本轮根因修复

### 1. DeepSeek 严格 OpenAI 兼容消息协议

旧 Agent 把动作序列化为普通 assistant 文本，却追加 `role=tool` 消息；DeepSeek 返回 400：tool 消息没有对应的 native `tool_calls`。已在 `backend/agent_runtime/runtime.py` 覆盖普通调用、缓存结果、自动恢复三条路径，改为模型可见的普通 user 工具观察，避免协议不一致。

### 2. 文本模型误接管图片语义 pipeline

DeepSeek Chat/V3 不支持 image content。旧 cloud bind 同时替换了 Agent 和全局 ingestion pipeline，导致语义阶段全部失败。已在 `backend/app.py` 拆分运行时：DeepSeek 只负责 Agent；原有本地 vision-capable gamma 继续负责图片导入、视觉语义、人物/事件索引和 event enrichment。两者的 worker、semantic stage、event summary 均使用 pipeline 自己的视觉 gamma。

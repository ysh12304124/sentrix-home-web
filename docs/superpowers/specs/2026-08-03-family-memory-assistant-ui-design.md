# 家庭记忆助手界面设计

## 目标

将现有单次记忆搜索页面改为中性、被动响应的家庭记忆助手会话界面。页面必须呈现 Agent 已有的证据、工具轨迹、澄清与推荐降级结果，不新增模型能力或事实写入。

## 架构

浏览器继续调用 `/api/assistant/turn`，并沿用 `conversation_id` 维持会话。前端保存当前会话的用户消息和助手结果；每条助手结果可展开查看证据、工具轨迹与算法依据。

## 技术栈

Plain browser JavaScript、现有 `src/api.js`、CSS、Node test runner。

## 交互

1. 页面命名为“家庭记忆助手”。
2. 用户消息和助手回答以连续气泡显示。
3. 助手回答显示置信度与证据状态；证据、工具调用、算法依据保持折叠。
4. 歧义结果显示候选按钮，将候选名称带入下一轮提问。
5. 首屏只给出中性示例问题，不主动推送回忆或推荐。
6. 无锚点推荐与证据不足显示助手的追问结果，不伪造答案。

## 验收

- 请求仍携带当前 `scope_id` 和 `conversation_id`。
- 已有工具轨迹、原始证据链接与算法依据可见。
- 切换相册时清空前端会话，避免视觉上跨空间延续。
- 不引入任何新的事实、实体或反馈写入 API。

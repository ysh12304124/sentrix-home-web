## 说明

- `gemma4-12B` 的回答均分由旧快照的 `1.000` 修正为 `0.973`：当前有效记录为 37 条，分布为 0 分 16 条、1 分 6 条、2 分 15 条。
- 旧表中的 `0.488`、`0.634`、`0.537` 等质量分也按同一套有效记录规则重新计算，因此分别修正为 `0.421`、`0.658`、`0.474`。
- 显存复测复用了原相册和 38 题问题，通过 100 Sentrix Agent 执行，不运行 PhotoBench Benchmark/Judge，也不保存本次模型回答。7 个模型均完成 38/38，零请求失败，原 run 的 `items` 哈希前后一致。
- `可比较显存 = 固定基础占用 + KV Cache 实际峰值`；`固定基础占用 = 空载模型进程显存 - vLLM 预分配 KV 池容量`；`KV 实际峰值 = KV 池容量 × 运行期间 KV 使用率峰值`。
- “可比较显存”适用于当前相同 vLLM 配置、同一 38 题工作负载的横向比较；不能直接等同于 llama.cpp、MLX、TensorRT-LLM 或端侧 NPU Runtime 的最终内存占用。
- `vLLM 进程预留峰值`包含预分配但未实际使用的 KV 池，仅用于部署配置追溯，不用于比较模型真实工作负载显存需求。
